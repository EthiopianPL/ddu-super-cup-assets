# DDU Super Cup — Static Asset Repository

Official static asset repository for **Dire Dawa University Super Cup Football Tournament**.

This repository hosts fixed static assets that do not require frequent administrative updates:
- Official university & tournament branding
- Team logos and department crests
- Group stage cover graphics
- Fallback placeholders

Dynamic administrator-uploaded player photographs and Man of the Match awards are hosted on **Cloudinary** and are **not** stored in this repository.

## 🔒 Guidelines
- Assets must be high-resolution transparent PNG or SVG files.
- Team logos should have a 1:1 square aspect ratio (minimum 256×256 pixels).
- Do not commit sensitive player documents, private photographs, or credentials.
